## 1. 题型识别框架

收到题目后，先判断属于以下哪种类型：

### 类型 A：概念问答题
**特征**：定义、简述、比较、说明
**例**："什么是 FEM？与 Ritz 法有何区别？"
**策略**：直接引用知识库定义，用对比表格说明

### 类型 B：公式推导题
**特征**：推导 Euler 方程、单元刚度矩阵、形函数等
**例**："推导 3 节点三角形单元的形函数和 $[B]$ 矩阵"
**策略**：分步展示推导过程，每个步骤说明物理意义

### 类型 C：数值计算题
**特征**：给定节点坐标、材料参数，计算刚度矩阵/应力
**例**："给定三角形单元节点坐标，材料 $E=200$GPa, $\nu=0.3$，求单元刚度矩阵"
**策略**：按 5 步计算模板操作

### 类型 D：证明题
**特征**：证明对称性、收敛性、性质等
**例**："证明总体刚度矩阵的对称性和半正定性"
**策略**：引用定义和已知定理，分步演绎

### 类型 E：编程题
**特征**：编写 FEM 代码、组装矩阵、求解
**策略**：提供伪代码/算法流程，着重数据结构设计

## 2. 常见题型系统化解题流程

### 2.1 泛函极值 / Euler 方程题

**输入**：泛函 $Q[y] = \int F(x,y,y')dx$

**步骤**：
```
① 写出 F
② 计算 ∂F/∂y
③ 计算 ∂F/∂y' 
④ 计算 d/dx(∂F/∂y')
⑤ 代入 Euler 方程: ∂F/∂y - d/dx(∂F/∂y') = 0
⑥ 得到 ODE
⑦ 代入边界条件求解
```

**参考**：[1-3 变分法](../01-Lecture-Notes/1-3-Variational-Methods.md) → §3.4 Euler 方程

### 2.2 形函数构造题

**输入**：单元类型（1D/2D 三角形/矩形）+ 节点数量

**步骤**：
```
① 确定多项式阶数（节点数决定）
② 若用自然坐标: 直接代入标准形函数
③ 若用物理坐标: 利用 N_i(x_j,y_j) = δ_ij 条件解
④ 验证: ΣN_i = 1 (刚体位移), N_i 在自身节点为 1
⑤ 对三角形: 面积坐标法最简便
```

**参考**：[1-6 单元构造](../01-Lecture-Notes/1-6-Element-Construction.md) → §6.2 二维情况

### 2.3 三角形单元刚度矩阵计算

**输入**：3 节点坐标 (x_i,y_i), (x_j,y_j), (x_m,y_m)，材料 E, ν，厚度 t，问题类型（平面应力/应变）

**步骤模板**：
```
Step 1: 计算单元面积 Δ_e
    Δ = ½|(x_j-x_i)(y_m-y_i) - (x_m-x_i)(y_j-y_i)|
    
Step 2: 计算 b_i, c_i 系数
    b_i = y_j - y_m,  c_i = x_m - x_j
    b_j = y_m - y_i,  c_j = x_i - x_m
    b_m = y_i - y_j,  c_m = x_j - x_i
    
Step 3: 构造 [B] 矩阵（3×6）
    [B] = 1/(2Δ) *
    [b_i  0  b_j  0  b_m  0]
    [0   c_i  0  c_j  0  c_m]
    [c_i b_i c_j b_j c_m b_m]
    
Step 4: 确定弹性矩阵 [D]
    平面应力或平面应变查对应公式
    
Step 5: 计算 [k]_e = t·Δ·[B]^T[D][B]
```

**参考**：[1-5 FEM 公式推导](../01-Lecture-Notes/1-5-FEM-Formulation.md) → §5.4 弹性力学平面问题

### 2.4 总体矩阵组装题

**输入**：多个单元的节点连接关系 + 各单元刚度矩阵

**步骤**：
```
① 建立总节点编号 → 单元局部节点编号映射表
② 创建 NP×NP 的零矩阵 [K]
③ 对每个单元 e:
   - 确定局部编号 (i,j,m) 对应的全局编号 (I,J,M)
   - 将 [k]_e 的分块按映射叠加到 [K]
④ 引入边界条件
⑤ 求解 [K]{δ} = {F}
```

**注意**：刚度矩阵带状稀疏，编程时用稀疏存储优化

### 2.5 张量运算题

**输入**：涉及 Kronecker δ、置换符号 e_ijk、指标记号的表达式

**步骤**：
```
① 识别哑指标（重复出现 → 求和）
② 识别自由指标（不重复 → 确定结果阶数）
③ 利用恒等式简化:
   - δ_ii = 3
   - δ_ij a_j = a_i
   - e_ijk e_ist = δ_js δ_kt - δ_jt δ_ks
```

**参考**：[1-2 张量分析](../01-Lecture-Notes/1-2-Tensor-Elasticity.md) → §2.2 张量引论

## 4. FEM 解题常见错误

| 错误 | 正确做法 |
|------|----------|
| 单元节点编号顺序随意 | 必须逆时针，保证面积为正 |
| 忘记引入边界条件就求解 | 必须先消除刚体位移，否则刚度矩阵奇异 |
| 平面问题混淆平面应力/应变 | 薄板 → 平面应力；厚板/长结构 → 平面应变 |
| 高斯积分阶数不足 | 2×2 对 Q4 单元精确积分双线性项 |
| 等参元 Jacobian 为负 | 检查单元形状，避免过度畸变 |
| 总体刚度矩阵稀疏性未利用 | 使用带状存储/稀疏矩阵技术 |
| Ritz 法和 Galerkin 法要求混淆 | Ritz 仅需位移边界，Galerkin 需全部边界 |
| 泛函是否线性的判断 | 必须同时检查齐次性和可加性 |
| 偏导与全导混淆 | Euler 方程中 $\partial F/\partial y$ 是偏导，$d/dx$ 是全导 |
| 变分与微分顺序 | 微分算子与变分算子可交换 $\frac{d}{dx}(\delta y) = \delta(y')$ |

## 6. 数值计算完整示例：Euler 方程 + Ritz 法对比

### 问题

求 $Q[y] = \int_0^1 (y'^2 - 4y^2)dx$ 的极值函数，$y(0)=0, y(1)=1$。

### 解法 A：Euler 方程法（精确解）

$F = y'^2 - 4y^2$，$F_y = -8y$，$F_{y'} = 2y'$

Euler 方程：$-8y - \frac{d}{dx}(2y') = 0$ → $y'' + 4y = 0$

特征方程 $r^2 + 4 = 0$，$r = \pm 2i$

通解：$y = C_1\cos 2x + C_2\sin 2x$

代入 $y(0)=0$ → $C_1 = 0$；$y(1)=1$ → $C_2 = 1/\sin 2$

**精确解**：$$y_{\text{exact}} = \frac{\sin 2x}{\sin 2}$$

### 解法 B：Ritz 法（一阶近似）

取试函数 $y = a_1 x(1-x) + a_2 x^2(1-x)$，使其满足 $y(0)=y(1)=0$。

对非齐次边界条件 $y(1)=1$，令 $y = w + x$，其中 $w$ 满足齐次边界 $w(0)=w(1)=0$。

代入原泛函得 $Q^*[w] = \int_0^1 (w'^2 - 4w^2 + 2w' - 8wx + \text{常数项})dx$

对应的微分方程：$-w'' - 4w = 4x$，$w(0)=w(1)=0$

取 $w \approx a_1 x(1-x) + a_2 x^2(1-x)$，代入 Galerkin 方程 $(Lw - f, \varphi_i)=0$：

解得 $a_1, a_2$，回代 $y = w + x$。

> 此例说明：**非齐次边界条件**在 Ritz 法中需先化为齐次边界再求解。
