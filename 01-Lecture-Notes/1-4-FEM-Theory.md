## 4.1 从变分法到数值解

### 4.1.1 问题的困境

第 3 章告诉我们：求泛函 $Q[y]$ 的极值 → 解 Euler 方程（一个 ODE/PDE）。

Euler 方程**大多数情况下无法解析求解**。只有极少数问题（最短路径、简支梁等）可以得到闭合形式的解。对实际工程问题，必须寻求**近似解法**。

### 4.1.2 变分问题的两类解

```
变分问题：δQ = 0
    │
    ├── Euler 法：转化为微分方程求解
    │   └── 需要求解 ODE/PDE（大多数情况很困难）
    │
    └── 直接法：绕过微分方程，直接求解变分问题
        ├── Euler 有限差分法（历史最早）
        ├── Ritz 法（最经典、最常用）  
        ├── Galerkin 法（特殊的 Ritz 法）
        └── 加权残量法（最一般的形式）
```

## 4.2 Euler 有限差分法

Euler 在 18 世纪提出的直接解法，思想简单：将连续变量离散化。

**步骤**：
1. 将 $[a,b]$ 等分为 $n+1$ 段，分点 $x_0=a, x_1, \ldots, x_n, x_{n+1}=b$
2. 用折线连接点 $(x_i, y_i)$，折线近似曲线
3. 用差商代替导数：$y'(x_i) \approx (y_{i+1} - y_i)/\Delta x$
4. 泛函 $Q[y]$ 转化为多元函数 $\Phi(y_1, \ldots, y_n)$
5. 极值条件 $\partial\Phi/\partial y_i = 0$ → 解出 $y_i$

当 $n \to \infty$，折线趋近真实解，$Q[y_n] \to \min Q[y]$，序列 $\{y_n\}$ 称为**极小化序列**。

> 这个方法的局限性：对二维问题网格划分困难，计算量大。

## 4.3 Ritz 法（核心方法）

### 4.3.1 基本思想

Ritz 法（1908）的核心洞察是：既然精确解在无限维函数空间中，我们可以将其投影到有限维子空间求近似解。

**思路**：将 trial function 设为有限个已知函数的线性组合：
$$u \approx u_n = \sum_{i=1}^n c_i \varphi_i$$

其中：
- $\varphi_i$ 是满足**边界条件**的基函数（已知，自己选取）
- $c_i$ 是待定系数（由极值条件确定）

### 4.3.2 求解步骤

```
① 选取满足边界条件的基函数 φ₁, φ₂, ..., φₙ
② 构造近似解 uₙ = Σ cᵢ φᵢ
③ 代入势能泛函 Π[uₙ] → 得 F(c₁, ..., cₙ)
④ 极值条件 ∂F/∂cᵢ = 0 → 线性方程组 Ka = b
⑤ 解方程组得 cᵢ，回代得近似解
```

### 4.3.3 数学推导

考虑算子方程 $\mathbf{T}u = f$ 的对应泛函：
$$Q[u] = (\mathbf{T}u, u) - 2(f, u)$$

其中 $(f, g) = \int_a^b f(x)g(x)dx$ 是内积。

取基函数 $\{\varphi_1, \ldots, \varphi_n\}$，张成 $n$ 维子空间：
$$u_n = \sum_{i=1}^n c_i \varphi_i$$

代入泛函：
$$Q[u_n] = \sum_{i,j=1}^n c_i c_j (\mathbf{T}\varphi_i, \varphi_j) - 2\sum_{i=1}^n c_i (f, \varphi_i) = F(c_1, \ldots, c_n)$$

极值条件 $\frac{\partial F}{\partial c_i} = 0$ 给出：
$$\sum_{j=1}^n (\mathbf{T}\varphi_i, \varphi_j)\,c_j = (f, \varphi_i) \quad (i=1,\ldots,n)$$

矩阵形式：
$$\boxed{\mathbf{K}\mathbf{c} = \mathbf{b}}$$

其中：
- $K_{ij} = (\mathbf{T}\varphi_i, \varphi_j)$ —— **广义刚度矩阵**（对称正定的）
- $b_i = (f, \varphi_i)$ —— **广义载荷向量**

### 4.3.4 系数矩阵的性质

1. **对称性**：$K_{ij} = K_{ji}$（当 $\mathbf{T}$ 为自伴算子时）
2. **正定性**：$\mathbf{c}^T\mathbf{K}\mathbf{c} > 0$ 对 $\mathbf{c} \neq 0$ → **解唯一**
3. 正定性的证明依赖于基函数的线性独立性和算子的正定性

### 4.3.5 限制条件

Ritz 法的最大限制：**试探函数必须满足全部边界条件**。

> 对于复杂几何形状，构造满足所有边界条件的基函数本身就是一项非常困难的任务，甚至比求解原问题还复杂。这就引出了 FEM 的突破——Courant 的分片近似。

## 4.4 Ritz 法数值算例

### 问题
求解 $u''(x) - u(x) = x$，$u(0) = u(1) = 0$。

### 精确解
特征方程 $r^2-1=0$，齐次解 $u_h = C_1 e^x + C_2 e^{-x}$，特解 $u_p = -x$
$$u_{\text{exact}}(x) = \frac{e}{e^2-1}(e^x - e^{-x}) - x$$

### Ritz 法求解

**基函数选取**：取满足 $u(0)=u(1)=0$ 的简单多项式：
$$\varphi_1 = x(1-x),\quad \varphi_2 = x^2(1-x),\quad \varphi_3 = x^3(1-x)$$

它们都满足 $\varphi_i(0) = \varphi_i(1) = 0$，且线性独立。

**构造近似解**：
$$u_3 = a_1 x(1-x) + a_2 x^2(1-x) + a_3 x^3(1-x)$$

**建立线性方程组**：通过 $\sum K_{ij}a_j = b_i$ 得：
$$\begin{pmatrix}0.3667 & 0.1833 & -0.1763 \\ 0.1833 & 0.1333 & -0.8940 \\ -0.1763 & -0.8940 & 0.0897\end{pmatrix}
\begin{pmatrix}a_1 \\ a_2 \\ a_3\end{pmatrix}
= \begin{pmatrix}-1/12 \\ -1/20 \\ -1/30\end{pmatrix}$$

解得 $a_1 = -0.4425, a_2 = 0.4635, a_3 = 0.0343$。

**对比**：
$$u_3(x) = 0.0343x^4 - 0.4292x^3 + 0.9060x^2 - 0.4425x$$

$$u_{\text{exact}}(0.5) = -0.0566,\quad u_3(0.5) = -0.0505$$

仅用 3 项基函数，误差约为 10%。增加基函数项数可进一步提高精度。

## 4.5 加权残量法（MWR）

### 4.5.1 基本思想

Ritz 法要求问题存在能量泛函。但**并非所有微分方程都有对应的能量泛函**（例如某些不可压流问题、传热问题等）。加权残量法（MWR）不需要泛函，直接处理微分方程。

设微分方程 $L(u) - f = 0$，近似解 $\tilde{u} = \sum c_i N_i$。

残差（余量）：
$$R = L(\tilde{u}) - f \neq 0$$

**MWR 核心**：迫使残差的加权积分为零：
$$(R, \omega_i) = \int_\Omega \omega_i R\,d\Omega = 0,\quad i=1,\ldots,n$$

不同的权函数 $\omega_i$ 选择 → 不同的方法。

### 4.5.2 五种方法的对比

| 方法 | 权函数 $\omega_i$ | 精度（一阶近似） | 特点 |
|------|-------------------|-----------------|------|
| **Galerkin 法** | 基函数 $N_i$ | **0.38%** | 应用最广，收敛性好 |
| **最小二乘法** | $\partial R/\partial c_i$ | **0.38%** | 数学意义明确 |
| 矩法 | $1, x, x^2, \ldots$ | 23.85% | 简单但精度低 |
| 配点法 | $\delta(x-x_i)$ | 21.16% | 实现最简单 |
| 子域法 | 子域上为 1 | 23.85% | 中间精度 |

数据来源：简支梁均布荷载一阶近似试函数 $w = c\sin(\pi x/l)$，对比精确解 $5ql^4/384EI$。

### 4.5.3 各方法的定义

**(a) Galerkin 法**（最重要）
$$\int_\Omega N_i R\,d\Omega = 0$$
- 权函数 = 基函数
- 对自伴算子，系数矩阵对称 → 与 Ritz 法等价

**(b) 最小二乘法**
$$\min\int_\Omega R^2 d\Omega \Rightarrow \int_\Omega R\frac{\partial R}{\partial c_i}d\Omega = 0$$
- 权函数 = $\partial R/\partial c_i$
- 等效于 Galerkin 法（对线性问题）

**(c) 配点法**
$$R(x_i) = 0,\quad i=1,\ldots,n$$
- 权函数 = Dirac delta $\delta(x-x_i)$
- 在选取的 $n$ 个点上强制残差为零

**(d) 矩法**
$$\int_\Omega x^{i-1}R\,d\Omega = 0,\quad i=1,\ldots,n$$
- 权函数 = 幂函数

**(e) 子域法**
$$\int_{\Omega_i} R\,d\Omega = 0,\quad i=1,\ldots,n$$
- 在每个子域上残差积分为零

## 4.6 Galerkin 法详解

### 4.6.1 Galerkin 法 vs Ritz 法

| 对比维度 | Ritz 法 | Galerkin 法 |
|----------|---------|-------------|
| 理论基础 | 最小势能原理（能量泛函） | 加权残量法（微分方程直接处理） |
| 试函数要求 | 满足位移（本质）边界条件 | 满足**全部**边界条件 |
| 适用范围 | 存在能量泛函的问题 | 任意微分方程 |
| 系数矩阵 | 对称正定 | 对自伴算子对称 |
| 力学判断 | 无需判断超静定次数 | 无需判断超静定次数 |

### 4.6.2 试函数合法性检验

**关键检查**：试函数是否满足所有边界条件？

以悬臂梁为例（$EI w'''' = q$）：
- $x=0$：$w(0)=0$（固定端位移），$w'(0)=0$（固定端转角）
- $x=l$：$w''(l)=0$（自由端弯矩），$w'''(l)=0$（自由端剪力）

**反面案例**：$w = a(1-\cos\frac{\pi x}{2l})$
- $w(0)=0$ ✅，$w'(0)=0$ ✅
- $w''(l)=0$ ✅，但**$w'''(l) = -a(\pi/2l)^3 \neq 0$** ❌
- 自由端剪力条件不满足 → 不是合法试函数

## 4.7 工程应用：梁的 Ritz/Galerkin 法求解

### 简支梁均布荷载

总势能：
$$\Pi = \frac12\int_0^l EI(w'')^2dx - \int_0^l qw\,dx$$

**试函数 1**：$w = a x(l-x)$
- 满足 $w(0)=w(l)=0$ ✅ 但不满足 $w''(0)=w''(l)=0$
- 解得 $a = ql^2/(24EI)$，$w_{\max} = ql^4/(96EI)$，**误差 ~20%**

**试函数 2**：$w = a\sin(\pi x/l)$
- 满足 $w(0)=w(l)=0$ ✅，且 $w''(0)=w''(l)=0$ ✅
- 解得 $a = 4ql^4/(\pi^5 EI)$，$w_{\max} \approx 0.01302\,ql^4/EI$，**误差 0.38%**

> **结论**：试函数的选择对精度影响巨大。如果试函数能正确反映问题的物理特征（本例中用正弦函数模拟挠曲形状），即使只有一项也能达到非常好的精度。

## 4.8 三种理解 FEM 的途径

```
FEM = 结构矩阵法（力学背景）
     = 变分法（能量原理）  
     = 加权残量法（数学统一）
```

三者统一：FEM 的本质是**在单元层面上应用 Galerkin/Ritz 法**。

## 4.9 概念辨析选择题

1. **Ritz 法的试函数必须满足** → 位移（本质）边界条件 ✅
2. **Galerkin 法的试函数必须满足** → 全部边界条件 ✅
3. **Galerkin 法和 Ritz 法何时等价？** → 存在能量泛函时 ✅
4. **哪种加权残量法与 Galerkin 法等价？** → 最小二乘法（对线性问题）✅
5. **Ritz 法需要判断超静定次数吗？** → 不需要 ✅
6. **Ritz 法位移解比真实值大还是小？** → 小（位移元下限性）✅
