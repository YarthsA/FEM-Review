## 4.1 引言：为什么需要直接法？

### 4.1.1 问题的困境

第 3 章建立了变分法的核心理论：泛函极值 $Q[y] = \int F(x,y,y')dx$ 的极值函数必须满足 Euler 方程：

$$F_y - \frac{d}{dx}F_{y'} = 0$$

这个 ODE（或 PDE）可以通过积分和边界条件来求解。**但大多数实际工程问题中，这个方程无法解析求解**。原因包括：

1. **PDE 的复杂性**：二维/三维问题的 Euler 方程是 PDE，只在极其简单的几何和边界条件下有闭式解
2. **非线性的困难**：即使得到 ODE，也往往是非线性的，无法直接积分得到解析表达式
3. **本构的复杂性**：材料非线性和几何非线性使方程进一步复杂化

因此，我们必须转向**近似解法**。

### 4.1.2 变分问题的两类解法

```
变分问题：δQ = 0（求泛函极值）
    │
    ├── Euler 法（间接法）
    │   └── 通过 Euler 方程转化为微分方程求解（精确但困难）
    │
    └── 直接法（近似法）
        ├── Euler 有限差分法（历史最早，但高维困难）
        ├── Ritz 法（最经典、最系统的方法）
        ├── Galerkin 法（Ritz 法的推广，更一般）
        └── 加权残量法（最一般的数学框架）
```

**直接法的核心思想**：不经过 Euler 方程，**直接从泛函（或微分方程）出发，构造有限个参数的近似解**。将无限维空间中的优化问题，转化为有限维子空间中的代数问题。

### 4.1.3 直接法的历史脉络

- **18 世纪**：Euler 提出有限差分法——用折线近似曲线，用差商代替导数
- **1908**：Ritz 提出系统性的直接法——用基函数线性组合构造近似解
- **1915**：Galerkin 推广了 Ritz 法——用加权残量的思想统一了变分法
- **1943**：Courant 提出分片近似——将 Ritz 法的"全局基函数"改为"分片基函数"
- **1960**：Clough 将 Courant 的思想发展为"有限单元法"

## 4.2 Euler 有限差分法

Euler 在 18 世纪提出的直接解法，是最早的变分近似解法。

### 4.2.1 基本步骤

考虑泛函 $Q[y] = \int_a^b F(x,y,y')dx$，边界条件 $y(a)=y_a, y(b)=y_b$。

**Step 1**：离散化。将 $[a,b]$ 等分为 $n+1$ 段：
$$x_0 = a,\; x_1,\; x_2,\;\ldots,\; x_n,\; x_{n+1} = b$$

**Step 2**：参数化。用折线连接点 $(x_i, y_i)$，其中 $y_i = y(x_i)$ 待定（$i=1,\ldots,n$）。注意 $y_0 = y_a$ 和 $y_{n+1} = y_b$ 是已知的。

**Step 3**：差商近似导数。在每个小区间上：
$$y'(x_i) \approx \frac{y_{i+1} - y_i}{\Delta x},\quad \Delta x = \frac{b-a}{n+1}$$

**Step 4**：泛函转为多元函数：
$$Q[y] \approx \sum_{i=0}^n F\left(x_i, y_i, \frac{y_{i+1} - y_i}{\Delta x}\right)\Delta x = \Phi(y_1, y_2, \ldots, y_n)$$

**Step 5**：极值条件：
$$\frac{\partial\Phi}{\partial y_i} = 0,\quad i = 1, 2, \ldots, n$$

解出 $y_1, \ldots, y_n$。

### 4.2.2 极小化序列

当 $n \to \infty$（即分段数无限增加）时：
- 折线趋近真实曲线
- 泛函值单调递减并收敛于真实极值：$Q[y_n] \to \min Q[y]$
- 序列 $\{y_1(x), y_2(x), \ldots, y_n(x), \ldots\}$ 称为**极小化序列（minimizing sequence）**

### 4.2.3 局限性

对于一维问题，有限差分法直观有效。但扩展到二维/三维时面临严重困难：网格节点的生成复杂，未知量数量随维度指数增长，组合爆炸。这促使了 Ritz 法和 FEM 的发展。

## 4.3 Ritz 法（最经典、最重要）

### 4.3.1 基本思路

Ritz 法的核心洞察：无限维函数空间 $H$ 中的优化问题可以**投影**到有限维子空间 $H_n \subset H$ 中求解。

**思想**：将近似解表示为已知基函数的线性组合：
$$u \approx u_n = \sum_{i=1}^n c_i \varphi_i$$

其中：
- $\varphi_i$ 是**满足边界条件**的已知基函数
- $c_i$ 是待定系数（由极值条件确定）

### 4.3.2 求解步骤

```
① 选择基函数 φ₁, φ₂, ..., φₙ（必须满足边界条件！）
② 构造近似解 uₙ = Σcᵢφᵢ
③ 代入泛函 Q[uₙ] → 得到关于 cᵢ 的多元函数 F(c₁,...,cₙ)
④ 极值条件 ∂F/∂cᵢ = 0 → 得线性方程组 Ka = b
⑤ 解方程组 → 回代得近似解
```

### 4.3.3 数学推导

考虑算子方程 $\mathbf{T}u = f$，假设对应的泛函为：
$$Q[u] = (\mathbf{T}u, u) - 2(f, u)$$

其中 $(f,g) = \int_a^b f(x)g(x)\,dx$ 是函数空间中的内积。

将近似解 $u_n = \sum_{i=1}^n c_i \varphi_i$ 代入：
$$\begin{aligned}
Q[u_n] &= (\mathbf{T}\sum_i c_i\varphi_i,\; \sum_j c_j\varphi_j) - 2(f, \sum_i c_i\varphi_i) \\
&= \sum_{i,j} c_i c_j (\mathbf{T}\varphi_i, \varphi_j) - 2\sum_i c_i (f, \varphi_i)
\end{aligned}$$

令：
$$K_{ij} = (\mathbf{T}\varphi_i, \varphi_j),\quad b_i = (f, \varphi_i)$$

则：
$$Q[u_n] = \sum_{i,j} c_i K_{ij} c_j - 2\sum_i c_i b_i = F(c_1, \ldots, c_n)$$

极值条件 $\frac{\partial F}{\partial c_i} = 0$ 给出：
$$\sum_{j=1}^n K_{ij} c_j = b_i,\quad i = 1, 2, \ldots, n$$

**矩阵形式**：
$$\boxed{\mathbf{K}\mathbf{c} = \mathbf{b}}$$

其中 $\mathbf{K}$ 是 $n\times n$ 的 Ritz 系数矩阵（广义刚度矩阵）。

### 4.3.4 系数矩阵的性质

1. **对称性**：$K_{ij} = K_{ji}$。证明：
   $$K_{ij} = (\mathbf{T}\varphi_i, \varphi_j) = (\mathbf{T}\varphi_j, \varphi_i) = K_{ji}$$
   这里利用了算子 $\mathbf{T}$ 的自伴性（$\mathbf{T}^* = \mathbf{T}$）。

2. **正定性**：$\mathbf{c}^T\mathbf{K}\mathbf{c} > 0$ 对任意 $\mathbf{c} \neq \mathbf{0}$。证明利用了 Scharz 不等式和基函数的线性独立性。正定性保证了**解的存在唯一性**。

3. **在 FEM 中**：由于基函数只在单元内非零（紧支撑），$\mathbf{K}$ 是**稀疏矩阵**——绝大多数元素为零。

### 4.3.5 Ritz 法的限制条件

**试函数必须满足所有的本质边界条件（位移边界条件）**。

所谓本质边界条件，是指泛函变分中与 $\delta y$ 相关的边界项所对应的条件。对于弹性力学的最小势能原理，本质边界条件就是**位移边界条件**。

> **为什么这是一个严重限制？**
> 对于复杂几何形状（如含孔板、尖角区域），构造一个**全局**满足所有位移边界条件的基函数本身就是极其困难的任务，甚至比求解原问题更复杂。这个限制直接催生了 FEM——将"全局试函数"变为"分片试函数"。

## 4.4 Ritz 法数值算例

### 4.4.1 问题与精确解

**问题**：求解 $u''(x) - u(x) = x$，$u(0)=u(1)=0$。

首先求精确解。特征方程 $r^2 - 1 = 0$，齐次解 $u_h = C_1 e^{x} + C_2 e^{-x}$。特解 $u_p = -x$。

通解：$u(x) = C_1 e^{x} + C_2 e^{-x} - x$

代入边界条件 $u(0)=0 \Rightarrow C_1 + C_2 = 0$，$u(1)=0 \Rightarrow C_1 e + C_2 e^{-1} - 1 = 0$。

解得 $C_1 = \frac{1}{e - e^{-1}} = \frac{e}{e^2 - 1}$，$C_2 = -\frac{e}{e^2-1}$。

精确解：
$$u_{\text{exact}}(x) = \frac{e}{e^2-1}(e^{x} - e^{-x}) - x$$

### 4.4.2 Ritz 法求解

**基函数选取**：取满足 $u(0)=u(1)=0$ 的简单多项式：
$$\varphi_1 = x(1-x),\quad \varphi_2 = x^2(1-x),\quad \varphi_3 = x^3(1-x)$$

它们都满足 $\varphi_i(0) = \varphi_i(1) = 0$，且线性独立。

**算子与泛函**：方程 $u'' - u = x$ 对应算子 $\mathbf{T}u = -u'' + u$，$f = -x$。

对应泛函的等价形式：
$$Q[u] = (\mathbf{T}u, u) - 2(f, u) = \int_0^1 [u'^2 + u^2 - 2(-x)u]dx = \int_0^1 [u'^2 + u^2 + 2xu]dx$$

代入 $u_3 = a_1 x(1-x) + a_2 x^2(1-x) + a_3 x^3(1-x)$ 到 $Q[u]$，由 $\partial Q/\partial a_i = 0$ 得方程组。

**线性方程组**：
$$\begin{pmatrix}
0.3667 & 0.1833 & -0.1763 \\
0.1833 & 0.1333 & -0.8940 \\
-0.1763 & -0.8940 & 0.0897
\end{pmatrix}
\begin{pmatrix}a_1 \\ a_2 \\ a_3\end{pmatrix}
= \begin{pmatrix}-1/12 \\ -1/20 \\ -1/30\end{pmatrix}$$

**解**：$a_1 = -0.4425$，$a_2 = 0.4635$，$a_3 = 0.0343$

**近似解**：
$$u_3(x) = 0.0343x^4 - 0.4292x^3 + 0.9060x^2 - 0.4425x$$

### 4.4.3 精度对比

| $x$ | 精确解 $u_{\text{exact}}$ | Ritz 解 $u_3$ | 误差 |
|-----|--------------------------|---------------|------|
| 0.0 | 0 | 0 | 0% |
| 0.25 | -0.0433 | -0.0397 | 8.3% |
| **0.5** | **-0.0566** | **-0.0505** | **10.8%** |
| 0.75 | -0.0389 | -0.0345 | 11.3% |
| 1.0 | 0 | 0 | 0% |

仅用 3 项多项式基函数，最大误差约 11%。增加基函数项数（$\varphi_4, \varphi_5, \ldots$）可快速提高精度。这是 Ritz 法的**收敛性**——更多基函数 → 更精确的解。

## 4.5 加权残量法（MWR）

### 4.5.1 为什么需要 MWR？

Ritz 法的局限：**需要问题存在能量泛函**。

不是所有微分方程都能找到对应的泛函（"逆变分问题"无解）。例如：
- 不可压缩 Navier-Stokes 方程
- 某些非线性传热/对流问题
- 非自伴算子控制的物理过程

MWR 不依赖泛函，直接处理微分方程，适用范围更广。

### 4.5.2 基本思想

设有微分方程 $L(u) - f = 0$，边界条件 $B(u) = 0$。

假设近似解 $\tilde{u} = \sum_{i=1}^n c_i N_i$，代入原方程一般不精确满足，产生**残差**：
$$R = L(\tilde{u}) - f \neq 0$$

**MWR 的核心**：迫使残差在加权积分意义下为零：
$$(R, \omega_i) = \int_\Omega \omega_i R\,d\Omega = 0,\quad i=1,2,\ldots,n$$

调整参数 $c_i$ 使上式成立。不同的权函数 $\omega_i$ 选择 → 不同的 MWR 方法。

### 4.5.3 几何解释

MWR 的几何解释很有启发性。设精确解为 $u$，近似解为 $u_0$。残差 $R = L(u_0) - f$ 度量了近似解偏离精确解的程度。

MWR 要求残差在权函数空间 $W$ 中的**投影为零**：
$$(L(u_0), \omega_i) = (f, \omega_i),\quad i=1,\ldots,n$$

即 $L(u_0)$ 和 $f$ 在 $W$ 中有相同的投影。当 $W$ 的维数 $n \to \infty$，解趋近精确解。

### 4.5.4 五种常用方法

**(a) Galerkin 法**（最重要、应用最广）

权函数取基函数本身 $\omega_i = N_i$：
$$\int_\Omega N_i R\,d\Omega = 0$$

特点：
- 对自伴算子，系数矩阵**对称**
- 当存在能量泛函时，**等价于 Ritz 法**
- 收敛性好，工程中最常用

**(b) 最小二乘法**

使残差平方的积分最小：
$$\frac{\partial}{\partial c_i}\int_\Omega R^2 d\Omega = 0 \Rightarrow \int_\Omega R\frac{\partial R}{\partial c_i}d\Omega = 0$$

权函数 $\omega_i = \partial R/\partial c_i$。对线性问题，等价于 Galerkin 法。

**(c) 配点法**

在 $n$ 个选定的点上强制残差为零：
$$R(x_i) = 0,\quad i=1,\ldots,n$$

权函数为 Dirac delta 函数 $\omega_i = \delta(x-x_i)$。实现最简单，精度较低。

**(d) 矩法**

权函数取幂函数 $1, x, x^2, \ldots$：
$$\int_\Omega x^{i-1}R\,d\Omega = 0,\quad i=1,\ldots,n$$

**(e) 子域法**

将域分为 $n$ 个子域，在每个子域上残差积分为零：
$$\int_{\Omega_i} R\,d\Omega = 0,\quad i=1,\ldots,n$$

### 4.5.5 精度对比（简支梁均布荷载）

试函数取一阶近似 $w = c\sin(\pi x/l)$，精确解跨中挠度为 $5ql^4/(384EI)$。

| 方法 | 权函数 | $w_{\max}$ 系数 | 误差 |
|------|--------|-----------------|------|
| **Galerkin 法** | $\sin(\pi x/l)$ | $4ql^4/(\pi^5 EI)$ | **0.38%** |
| **最小二乘法** | $\partial R/\partial c$ | 同上 | **0.38%** |
| 矩法 | $1$ | $ql^4/(2\pi^3 EI)$ | 23.85% |
| 配点法 | $\delta(x-l/2)$ | $ql^4/(\pi^4 EI)$ | 21.16% |
| 子域法 | 子域上 1 | $ql^4/(2\pi^3 EI)$ | 23.85% |

Galerkin 法和最小二乘法的精度远高于其他三种。这是因为这两种方法的权函数与问题的性质（正弦形的挠曲线）更为匹配。

## 4.6 Galerkin 法详解

### 4.6.1 Galerkin 法方程

对微分方程 $L(u) - f = 0$，令 $u_n = \sum c_i N_i$：
$$\int_\Omega N_i [L(\sum c_j N_j) - f]\,d\Omega = 0,\quad i=1,\ldots,n$$

对线性算子 $L$：
$$\sum c_j \int_\Omega N_i L(N_j)\,d\Omega = \int_\Omega N_i f\,d\Omega$$

矩阵形式：$\mathbf{K}\mathbf{c} = \mathbf{b}$，其中 $K_{ij} = \int_\Omega N_i L(N_j)\,d\Omega$。

### 4.6.2 Galerkin 法 vs Ritz 法

| 对比维度 | Ritz 法 | Galerkin 法 |
|----------|---------|-------------|
| 理论基础 | 最小势能原理（需要能量泛函） | 加权残量法（直接处理微分方程） |
| 试函数要求 | 满足位移（本质）边界条件 | 满足**全部**边界条件 |
| 适用范围 | 存在能量泛函的问题 | 任意微分方程（包括无泛函情形） |
| 系数矩阵 | 自动对称正定 | 自伴算子时对称，否则不对称 |
| 力学背景 | 无需判断静不定次数 | 无需判断静不定次数 |
| **联系** | 当存在泛函时，两者等价 |||

### 4.6.3 Galerkin 法的试函数合法性检验

**关键检查项**：试函数是否满足**所有**边界条件？包括：
- 本质边界条件（位移/温度等给定值）
- 自然边界条件（力/热流等给定值）

**示例**：悬臂梁（$EI w'''' = q$）的自由端

| 位置 | 边界条件 | 类型 |
|------|----------|------|
| $x=0$ 固定端 | $w(0)=0$ | 本质 |
| $x=0$ 固定端 | $w'(0)=0$ | 本质 |
| $x=l$ 自由端 | $w''(l)=0$ | 自然（弯矩为零）|
| $x=l$ 自由端 | $w'''(l)=0$ | 自然（剪力为零）|

**反面案例**：检验 $w = a(1 - \cos\frac{\pi x}{2l})$

- $w(0) = a(1-1) = 0$ ✅
- $w'(0) = a\cdot\frac{\pi}{2l}\cdot 0 = 0$ ✅
- $w''(l) = a(\frac{\pi}{2l})^2\cos\frac{\pi}{2} = 0$ ✅
- **$w'''(l) = -a(\frac{\pi}{2l})^3\sin\frac{\pi}{2} = -a(\frac{\pi}{2l})^3 \neq 0$ ❌**

**结论**：自由端剪力不为零，此函数不满足自然边界条件。对于 **Ritz 法**，它可能被接受（因为 Ritz 只要求位移 BC）；对于 **Galerkin 法**，它不合格（Galerkin 要求全部 BC）。

### 4.6.4 工程应用：简支梁的 Ritz 法

总势能：
$$\Pi = \frac12\int_0^l EI(w'')^2dx - \int_0^l q w\,dx$$

**试函数 1**：$w = a\,x(l-x)$

满足 $w(0)=w(l)=0$（本质 BC），但 $w''(0)=w''(l) \neq 0$（自然 BC）。

代入得 $\Pi = EI l a^2 - \frac{q l^3}{6} a$

$\partial\Pi/\partial a = 0 \Rightarrow a = \frac{ql^2}{24EI}$

$w_{\max} = w(l/2) = \frac{ql^4}{96EI}$，**误差约 20%**（精确 $5ql^4/384EI$）

**试函数 2**：$w = a\sin(\pi x/l)$

满足 $w(0)=w(l)=0$ 和 $w''(0)=w''(l)=0$（本质+自然 BC）。

代入得 $\Pi = \frac{EI\pi^4}{4l^3}a^2 - \frac{2ql}{\pi}a$

$\partial\Pi/\partial a = 0 \Rightarrow a = \frac{4ql^4}{\pi^5 EI}$

$w_{\max} = a = \frac{4ql^4}{\pi^5 EI} \approx 0.01307\frac{ql^4}{EI}$，**误差仅 0.38%**

**结论**：试函数的选择对精度影响巨大。反映问题物理特征的试函数（如正弦函数模拟挠曲形状）即使只有一项也能达到很高精度。

## 4.7 理解 FEM 的三种途径

### 途径一：结构矩阵法

FEM 最早的理论渊源来自**结构力学的矩阵位移法**：
- 结构由杆、梁等构件组成 → 每个构件是"单元"
- 用矩阵形式建立节点力与节点位移的关系
- Turner, Clough, Martin, Topp (1956) 将此法推广到平面应力问题的三角形/矩形单元

力学概念清晰、公式有明确的结构力学含义——这是工程师最容易理解的角度。

### 途径二：变分法（能量法）

基于**最小势能原理**或**虚位移原理**：
- 将弹性力学 PDE 问题转化为泛函极值问题
- 用 Ritz 法在有限维子空间中求近似解
- FEM 可以看作"在单元层面上应用 Ritz 法"

理论最坚实，是 FEM 的数学基础——这是应用数学家偏好的角度。

### 途径三：加权残量法

直接从微分方程出发，不依赖能量泛函：
- 通过 Galerkin 法与 FEM 自然结合
- 适用于不存在变分原理的问题
- 系数矩阵不一定对称

**三者统一**：当存在能量泛函时，三种途径等价。FEM 的本质是在**单元层面上**应用 Galerkin/Ritz 法的结果。

## 4.8 FEM 误差来源分析

| 误差类型 | 来源 | 对策 |
|----------|------|------|
| **离散误差** | 连续域被有限单元近似（几何近似） | 加密网格 |
| **插值误差** | 低阶多项式近似真实场 | 提高单元阶数（h→p） |
| **数值积分误差** | Gauss 积分近似精确积分 | 增加积分点数 |
| **舍入误差** | 计算机浮点数有限精度 | 双精度、稳定算法 |

## 4.9 历史发展脉络

| 年份 | 人物 | 贡献 |
|------|------|------|
| 1755 | Euler, Lagrange | Euler-Lagrange 方程 |
| 1908 | W. Ritz | Ritz 直接法 |
| 1915 | B. Galerkin | Galerkin 法 |
| 1943 | R. Courant | 分片三角形近似（FEM 思想前驱）|
| 1956 | Turner, Clough, Martin, Topp | 矩阵位移法解平面应力 |
| 1960 | R. Clough | 首次提出"Finite Element Method" |
| 1963 | Besseling, Melosh | 确认 FEM 是 Ritz 法的变分形式 |
| 1965 | Zienkiewicz, Cheung | 推广到场问题（热、渗流等）|
| 1967 | Zienkiewicz | 出版第一本 FEM 专著 |
| 1969 | Szabo, Lee | 加权残量法用于非结构问题 |

### 中国学者的贡献
- **陈伯屏**：结构矩阵法
- **钱令希**：余能原理
- **钱伟长、胡海昌**：广义变分原理
- **冯康**：有限元理论
