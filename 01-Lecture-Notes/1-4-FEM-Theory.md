# 第4章：FEM 理论基础 — Ritz 法、Galerkin 法与加权残量法

> 本章连接变分法的数学理论与有限元的具体实现。
> 核心问题：当我们无法获得微分方程的精确解时，如何用有限个参数的近似解逼近真实解？

---

## 1. 变分问题的直接法

### 1.1 Euler 有限差分法

Euler 最早提出的直接解法。思想简单：将连续变量离散化。

**步骤**：
1. 将区间 $[a,b]$ 等分为 $n+1$ 段，分点 $x_0=a, x_1, \ldots, x_n, x_{n+1}=b$
2. 用折线连接点 $(x_i, y_i)$，其中 $y_i = y(x_i)$ 未知
3. 用差商代替导数：$y' \approx (y_{i+1}-y_i)/\Delta x$
4. 泛函 $Q[y]$ 近似为多元函数 $\Phi(y_1,\ldots,y_n)$
5. 极值条件 $\partial\Phi/\partial y_i = 0$ → 解出各 $y_i$

当 $n \to \infty$ 时，折线趋近真实解，泛函值单调递减 → **极小化序列**。

---

### 1.2 Ritz 法（最经典）

#### 核心思路
将无限维函数空间的优化问题，投影到有限维子空间上求解。

**Ritz 法求解步骤**：

```
① 选取满足边界条件的基函数 φ₁, φ₂, ..., φₙ
② 构造近似解 uₙ = Σ aᵢ φᵢ
③ 代入势能泛函 Π[uₙ] → 得 F(a₁,...,aₙ)
④ 极值条件 ∂F/∂aᵢ = 0 → 线性方程组 Ka = b
⑤ 解方程组得 aᵢ，回代得近似解
```

#### 数学推导

考虑算子方程 $\mathbf{T}u = f$，其对应的泛函为：
$$Q[u] = (\mathbf{T}u, u) - 2(f,u)$$

引入基函数 $\{\varphi_1, \ldots, \varphi_n\}$，张成子空间 $H_n$，近似解：
$$u_n = \sum_{i=1}^n a_i \varphi_i$$

代入泛函：
$$Q[u_n] = \sum_{i,j=1}^n a_i a_j (\mathbf{T}\varphi_i, \varphi_j) - 2\sum_{i=1}^n a_i (f, \varphi_i) = F(a_1, \ldots, a_n)$$

极值条件 $\frac{\partial F}{\partial a_i} = 0$ 得：
$$\sum_{j=1}^n a_j (\mathbf{T}\varphi_i, \varphi_j) = (f, \varphi_i),\quad i=1,\ldots,n$$

矩阵形式：
$$\boxed{\mathbf{Ka} = \mathbf{b}}$$
其中 $K_{ij} = (\mathbf{T}\varphi_i, \varphi_j)$，$b_i = (f, \varphi_i)$。

#### 系数矩阵的性质
- **对称性**：$K_{ij} = K_{ji}$（由于算子 $\mathbf{T}$ 的自伴性）
- **正定性**：$\mathbf{c}^T\mathbf{K}\mathbf{c} > 0$ 对任意 $\mathbf{c} \neq 0$ → 解唯一

#### 收敛条件
Ritz 法收敛的充分条件：基函数 $\{\varphi_i\}$ 在解空间中**完备**，即 $\forall u \in H$，$\exists u_n \in H_n$ 使 $\|u-u_n\| \to 0$。

#### 局限（关键！）
**试探函数必须满足所有边界条件**。对于复杂几何形状，构造满足边界条件的基函数本身就非常困难，甚至比求解原问题还复杂。

---

### 1.3 Ritz 法数值算例

**问题**：$u''(x) - u(x) = x$，$u(0)=u(1)=0$，求近似解。

**精确解**：$u(x) = \frac{e}{e^2-1}(e^x - e^{-x}) - x$

**Ritz 法**：
取基函数 $\varphi_1 = x(1-x)$，$\varphi_2 = x^2(1-x)$，$\varphi_3 = x^3(1-x)$
它们均满足 $\varphi_i(0)=\varphi_i(1)=0$。

解线性方程组得：
$$u_3(x) = 0.0343x^4 - 0.4292x^3 + 0.9060x^2 - 0.4425x$$

在 $x=0.5$ 处比较：$u_{\text{exact}}(0.5) = -0.0566$，$u_3(0.5) = -0.0505$

> 仅 3 项基函数就达到了约 10% 的精度。增加基函数项数可进一步提高精度。

## 2. 加权残量法 (Method of Weighted Residuals, MWR)

### 2.1 基本思想

对于微分方程 $L(u) - f = 0$，假设近似解 $\tilde{u} = \sum c_i N_i$。

将 $\tilde{u}$ 代入原方程，一般不会精确满足，产生**残差**：
$$R = L(\tilde{u}) - f \neq 0$$

**MWR 的核心**：调整参数 $c_i$，使残差 $R$ 在权函数空间 $W$ 中的投影为零：
$$(R, \omega_i) = \int_\Omega \omega_i R\,d\Omega = 0,\quad i=1,\ldots,n$$

### 2.2 五种常用方法对比

| 方法 | 权函数 $\omega_i$ | 特点 | 精度（一阶近似） |
|------|-------------------|------|-----------------|
| **Galerkin 法** | 基函数 $N_i$ | 应用最广、收敛性好 | 0.38% |
| **最小二乘法** | $\partial R/\partial c_i$ | 数学意义明确 | 0.38% |
| 矩法 | $1, x, x^2, \ldots$ | 简单但精度低 | 23.85% |
| 配点法 | $\delta(x-x_i)$ | 实现最简单 | 21.16% |
| 子域法 | 子域上为 1 | 中间精度 | 23.85% |

> 精度数据来自简支梁均布荷载的一阶近似（试函数 $w = c\sin\frac{\pi x}{l}$，跨中挠度对比精确解 $5ql^4/384EI$）。

### 2.3 各方法的详细定义

#### (a) Galerkin 法（最重要）
权函数取基函数本身 $\omega_i = N_i$：
$$\int_\Omega N_i R\,d\Omega = 0$$

**优点**：
- 系数矩阵对称（对自伴算子）
- 与 Ritz 法在变分问题中等价
- 收敛性好

#### (b) 最小二乘法 (Least Squares)
使残差平方积分最小：
$$\frac{\partial}{\partial c_i}\int_\Omega R^2 d\Omega = 0 \Rightarrow \int_\Omega R\frac{\partial R}{\partial c_i} d\Omega = 0$$

权函数 $\omega_i = \partial R/\partial c_i$。代数上等价于 Galerkin 法，得到的解也相同。

#### (c) 配点法 (Collocation)
在 $n$ 个选定的点上强制残差为零：
$$R(x_i) = 0,\quad i=1,\ldots,n$$

权函数为 Dirac delta 函数 $\omega_i = \delta(x-x_i)$。实现最简单，但精度较低。

#### (d) 矩法 (Moment Method)
权函数取幂函数 $1, x, x^2, \ldots$：
$$\int_\Omega x^{i-1}R\,d\Omega = 0,\quad i=1,\ldots,n$$

#### (e) 子域法 (Subdomain Method)
将求解域分为 $n$ 个子域，在每个子域上残差积分为零：
$$\int_{\Omega_i} R\,d\Omega = 0,\quad i=1,\ldots,n$$

### 2.4 何时用加权残量法？

当微分方程**找不到对应的能量泛函**时（即逆变分问题无解），Ritz 法和最小势能原理无法使用。此时 MWR 是唯一的选择。Galerkin 法是 MWR 中最常用的一种。

## 3. Galerkin 法详解

### 3.1 Galerkin 法 vs Ritz 法

| 对比维度 | Ritz 法 | Galerkin 法 |
|----------|--------|-------------|
| 出发点 | 最小势能原理（能量泛函） | 加权残量法（微分方程） |
| 试探函数要求 | 满足位移（本质）边界条件 | 满足**全部**边界条件（位移+力） |
| 适用范围 | 存在能量泛函的问题 | 任意微分方程 |
| 系数矩阵 | 对称 | 对称（自伴算子） |
| 力学背景 | 无需判断超静定次数 | 无需判断超静定次数 |

### 3.2 Galerkin 法的求解方程

对于梁的弯曲问题 $EI w'''' = q$，Galekin 法：
$$\int_0^l (EI w_n'''' - q)\,\varphi_i\,dx = 0,\quad i=1,\ldots,n$$

其中 $w_n = \sum a_i\varphi_i$ 为试探函数，$\varphi_i$ 同时作为基函数和权函数。

### 3.3 Galerkin 试探函数的合法性

**关键检查项**：试探函数是否满足**全部**边界条件？

以悬臂梁为例：
- 固定端（$x=0$）：$w(0)=0$（位移），$w'(0)=0$（转角）
- 自由端（$x=l$）：$w''(l)=0$（弯矩），$w'''(l)=0$（剪力）

**反面案例**：$w = a(1 - \cos\frac{\pi x}{2l})$
- $w(0)=0$ ✅，$w'(0)=0$ ✅
- $w''(l)=0$ ✅，但 **$w'''(l) = -a(\pi/2l)^3 \neq 0$** ❌
- 剪力不为零 → 不是合法试探函数

### 3.4 Ritz 法和 Galerkin 法的联系

当微分方程存在能量泛函时，Galerkin 法的离散方程与 Ritz 法完全相同。因此：
> **对于自伴正定算子，Galerkin 法和 Ritz 法等价。**

FEM 可以看作是"在单元层面上应用 Galerkin/Ritz 法的结果"。

## 4. 深入理解 FEM 的三种途径

### 途径一：结构矩阵法
- 源自结构力学的矩阵位移法 → Turner & Clough (1956)
- 力学概念清晰，公式具有明确的结构力学含义
- 将结构离散为杆、梁等单元，用矩阵代数求解

### 途径二：变分法
- 基于最小势能原理 / 虚位移原理
- 将弹性力学边值问题转化为泛函极值问题
- 理论基础最坚实、应用面最广

### 途径三：加权残量法
- 直接处理微分方程（无需能量泛函）
- 适用于不存在变分原理的问题（如不可压流动、传热）
- 通过 Galerkin 法与 FEM 自然结合

> **三者统一**：FEM 的通用性在于——
> 有能量泛函时用变分法（Ritz）推导；
> 无能量泛函时用 Galerkin 法推导；
> 两者在自伴算子情形下等价。

## 5. Ritz/Galerkin 法的工程应用：梁的 Ritz 法求解

### 简支梁均布荷载

总势能：
$$\Pi = \frac12\int_0^l EI(w'')^2dx - \int_0^l qw\,dx$$

#### 一阶近似 1：$w = a x(l-x)$
- 满足 $w(0)=w(l)=0$ ✅
- 代入得 $a = ql^2/(24EI)$
- 跨中挠度 $w_{\max} = ql^4/(96EI)$，**误差 ~20%** ❌

#### 一阶近似 2：$w = a\sin(\pi x/l)$
- 满足 $w(0)=w(l)=0$ ✅，且 $w''(0)=w''(l)=0$（简支力边界也满足）
- 代入得 $a = 4ql^4/(\pi^5 EI)$
- 跨中挠度 $w_{\max} \approx ql^4/(\pi^5 EI) \cdot 4$，**误差 0.38%** ✅

> **重要结论**：试探函数的选择对精度影响巨大。适当地反映问题的物理特征（本例中用正弦函数模拟挠曲形状），即使只有一项也能达到很高的精度。

### 两端固定梁均布荷载（Galerkin 法）

取 $w = a(1-\cos\frac{2\pi x}{l})$：
- $w(0)=w(l)=0$ ✅，$w'(0)=w'(l)=0$ ✅（位移边界全部满足）
- 力边界自动满足（对称性）
- Galerkin 方程：$\int_0^l (EI w'''' - q)w\,dx = 0$
- 解得 $a = \frac{ql^4}{8\pi^4 EI}$
- $w_{\max} \approx 0.01302\frac{ql^4}{EI}$，精确解 $0.01302\frac{ql^4}{EI}$，**精度极高**

## 7. 总结：各方法的关系图谱

```
微分方程边值问题
├── 有能量泛函 → 变分原理（最小势能）
│   ├── 精确求解 → Euler 方程（但太难解）
│   └── 近似求解
│       ├── Ritz 法（整体 trial function）→ 需满足位移BC
│       └── FEM（分片 trial function）→ Ritz 在单元上的应用
│
└── 无能量泛函 → 加权残量法
    ├── Galerkin 法 → 权函数=基函数，需满足全部BC
    ├── 最小二乘法 → 精度高，数学意义明确
    ├── 配点法 → 实现简单，精度一般
    ├── 矩法 → 精度较低
    └── 子域法 → 精度较低
```

FEM 的优越之处在于：
1. 将 Ritz/Galerkin 法中**全局试函数**替换为**分片（单元级）试函数**
2. 降低了试函数的光滑度要求（从 $C^1$ 降到 $C^0$，甚至可间断）
3. 程序实现标准化、自动化
4. 适用性问题不受限制（固体、流体、热、电磁均可）
